# Documentação de domínio

Este é um repositório single-context.

## Antes de explorar

Consulte, quando existirem:

- `CONTEXT.md` na raiz;
- `docs/adr/` para decisões arquiteturais relevantes;
- `AGENTS.md` como orientação operacional do repositório.

Se `CONTEXT.md` ou `docs/adr/` ainda não existirem, prossiga sem criá-los
apenas por causa desta configuração. Eles devem nascer quando uma decisão ou
termo de domínio real precisar ser registrado.

## Vocabulário

Use os termos definidos no `CONTEXT.md` para nomear conceitos de domínio.
Quando o documento ainda não definir um termo necessário, registre a lacuna em
vez de criar sinônimos silenciosos.

## Decisões

Se uma mudança contrariar um ADR existente, destaque o conflito e explique por
que a decisão merece ser reaberta antes de implementá-la.
