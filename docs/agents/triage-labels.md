# Triage labels

As skills usam cinco papéis canônicos de triagem. Neste repositório, os nomes
dos papéis e dos rótulos são iguais:

| Papel canônico | Rótulo | Significado |
|---|---|---|
| `needs-triage` | `needs-triage` | A iniciativa ainda precisa de avaliação |
| `needs-info` | `needs-info` | Falta informação do solicitante |
| `ready-for-agent` | `ready-for-agent` | Está especificado e pronto para um agente |
| `ready-for-human` | `ready-for-human` | Exige implementação ou decisão humana |
| `wontfix` | `wontfix` | Não será executado |

Tickets publicados por `to-tickets` recebem `ready-for-agent`, salvo instrução
contrária.
